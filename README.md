## 📖 Sobre

O **Ferramentas Recomendadas** reúne as **versões das ferramentas** indicadas pelo desenvolvedor para trabalhar com mais **compatibilidade**, **estabilidade** e **praticidade**. 🛠️

A ideia é servir como referência rápida: antes de começar um projeto, é só conferir quais versões usar e evitar problemas de configuração.
